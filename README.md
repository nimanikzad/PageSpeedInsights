# آموزش کامل PageSpeed Insights از صفر تا صد 🚀

**مینی‌دوره‌ی رایگان و فارسی افزایش سرعت سایت و بهینه‌سازی برای PageSpeed Insights گوگل**؛ با توضیح ساده و خودمونی همه‌ی معیارها: Core Web Vitals (یعنی LCP، INP و CLS)، نمره‌ی Performance در Lighthouse، معیارهای FCP، TBT و Speed Index، دسترسی‌پذیری (Accessibility)، اصول درست (Best Practices) و سئوی پایه.

🔗 **دیدن دوره به‌صورت آنلاین:** [nimanikzad.github.io/PageSpeedInsights](https://nimanikzad.github.io/PageSpeedInsights/)

---

## 📌 این پروژه چیه؟

یه صفحه‌ی آموزشی تک‌فایلی (`index.html`) که مثل یه مینی‌دوره، قدم‌به‌قدم یاد می‌ده:

- ابزار **PageSpeed Insights** چیه و فرق **داده‌ی واقعی کاربرها** (Field Data / CrUX) با **تست آزمایشگاهی** (Lab Data / Lighthouse) چیه
- نمره‌ی **۰ تا ۱۰۰** چطور حساب می‌شه و وزن هر معیار چقدره
- چطور **LCP** رو پایین بیاری (عکس‌ها، سرور، CDN، کش، fetchpriority)
- چطور **INP** و **TBT** رو بهتر کنی (جاوااسکریپت، اسکریپت‌های شخص ثالث، Long Taskها)
- چطور **CLS** رو صفر کنی (ابعاد عکس، فونت، تبلیغ‌ها)
- معنی همه‌ی **Insights** و **Diagnostics** گزارش، به‌روز با **Lighthouse 13**
- چک‌لیست **دسترسی‌پذیری**، **Best Practices** و **سئو**
- نکته‌های **وردپرس** و **باورهای غلط** رایج درباره‌ی پیج اسپید

## 🎯 خلاصه‌ی معیارها

| معیار | یعنی چی؟ | خوب | ضعیف |
|---|---|---|---|
| **LCP** | نمایش بزرگ‌ترین محتوای بالای صفحه | تا ۲٫۵ ثانیه | بیش از ۴ ثانیه |
| **INP** | سرعت پاسخ به کلیک و تایپ | تا ۲۰۰ میلی‌ثانیه | بیش از ۵۰۰ میلی‌ثانیه |
| **CLS** | جابه‌جایی ناگهانی چیدمان | تا ۰٫۱ | بیش از ۰٫۲۵ |
| **FCP** | نمایش اولین محتوا | تا ۱٫۸ ثانیه | بیش از ۳ ثانیه |
| **TTFB** | رسیدن اولین بایت از سرور | تا ۰٫۸ ثانیه | بیش از ۱٫۸ ثانیه |

وزن معیارها در نمره‌ی Performance: معیار TBT ۳۰٪، LCP ۲۵٪، CLS ۲۵٪، FCP ۱۰٪ و Speed Index ۱۰٪.

## ⚡ این صفحه خودش چقدر سریعه؟

تمرین همین دوره است! 😉

- بدون هیچ عکسی؛ آیکون‌ها ایموجی هستن
- همه‌ی CSS و JS داخل خود فایل؛ بدون درخواست مسدودکننده‌ی اضافه
- فونت وزیرمتن با `font-display: swap` و `preconnect`
- اعمال تم پیش از رندر، برای اینکه صفحه چشمک نزنه و CLS نگیره

اگه می‌خوای حتی سریع‌ترش کنی، فونت وزیرمتن رو روی همین مخزن قرار بده (self-host) تا به Google Fonts وابسته نباشی.
